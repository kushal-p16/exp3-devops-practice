# Experiment 03 -- Maven Project, JUnit Testing and GitHub Actions

## Aim

To create a Maven project in Eclipse, implement a Java Grade Calculator,
execute JUnit tests, build a JAR file, and push the project to GitHub
with a GitHub Actions workflow that builds the project automatically.

## Tools and technologies

-   Eclipse IDE for Java Developers
-   Java Development Kit (JDK) 17
-   Apache Maven
-   JUnit 5
-   Git
-   GitHub
-   GitHub Actions

## 1. Create a Maven project in Eclipse

1.  Open Eclipse IDE.

2.  Select **File → New → Maven Project**.

3.  Click **Next**.

4.  Select the **Maven Archetype** option.

5.  In the filter/search field, search for `maven-archetype-quickstart`.

6.  Select the quickstart archetype and click **Next**.

7.  Enter the project details:

      Field         Value
      ------------- ---------------------
      Group Id      `com.example`
      Artifact Id   `maven-github-demo`
      Version       `1.0-SNAPSHOT`
      Package       `com.example`

8.  Click **Finish**.

The project is created with a Maven source structure.

## 2. Project structure

The application and test source files are kept in separate folders:

``` text
maven-github-demo/
├── src/
│   ├── main/
│   │   └── java/
│   │       └── com/example/maven_github_demo/
│   │           └── GradeCalculator.java
│   └── test/
│       └── java/
│           └── com/example/maven_github_demo/
│               └── GradeCalculatorTest.java
├── pom.xml
└── target/                 # Generated by Maven
```

> **Package note:** The project was initially generated with
> `com.example`. In the configured project, the Java package is retained
> as `com.example.maven_github_demo`. Use this same package declaration
> in both Java files and keep the files in the matching package folders.

## 3. Configure `pom.xml`

Open `pom.xml` and configure Java 17, JUnit 5, and the Maven Surefire
Plugin. The following is a complete example:

``` xml
<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0
         https://maven.apache.org/xsd/maven-4.0.0.xsd">

    <modelVersion>4.0.0</modelVersion>

    <groupId>com.example</groupId>
    <artifactId>maven-github-demo</artifactId>
    <version>1.0-SNAPSHOT</version>

    <properties>
        <maven.compiler.source>17</maven.compiler.source>
        <maven.compiler.target>17</maven.compiler.target>
        <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>
    </properties>

    <dependencies>
        <dependency>
            <groupId>org.junit.jupiter</groupId>
            <artifactId>junit-jupiter</artifactId>
            <version>5.10.2</version>
            <scope>test</scope>
        </dependency>
    </dependencies>

    <build>
        <plugins>
            <plugin>
                <groupId>org.apache.maven.plugins</groupId>
                <artifactId>maven-surefire-plugin</artifactId>
                <version>3.2.5</version>
            </plugin>
        </plugins>
    </build>

</project>
```

Save the file.

## 4. Create the Grade Calculator application

1.  Open `src/main/java`.
2.  Open the package `com.example.maven_github_demo`.
3.  Rename the generated `App.java` to `GradeCalculator.java`, or create
    a new Java class with that name.
4.  Replace the application code with:

``` java
package com.example.maven_github_demo;

public class GradeCalculator {

    public static int calculateTotal(int m1, int m2, int m3) {
        return m1 + m2 + m3;
    }

    public static double calculateAverage(int m1, int m2, int m3) {
        return calculateTotal(m1, m2, m3) / 3.0;
    }

    public static boolean isPass(double average) {
        return average >= 40.0;
    }

    public static void main(String[] args) {
        int m1 = 75, m2 = 68, m3 = 82;

        int total = calculateTotal(m1, m2, m3);
        double average = calculateAverage(m1, m2, m3);

        System.out.println("Total   : " + total);
        System.out.println("Average : " + average);
        System.out.println("Result  : "
                + (isPass(average) ? "PASS" : "FAIL"));
    }
}
```

5.  Save the file.
6.  Right-click `GradeCalculator.java` and select **Run As → Java
    Application**.

Expected console output:

``` text
Total   : 225
Average : 75.0
Result  : PASS
```

## 5. Create the JUnit test class

1.  Open `src/test/java`.
2.  Open the package `com.example.maven_github_demo`.
3.  Rename the generated `AppTest.java` to `GradeCalculatorTest.java`,
    or create a new test class with that name.
4.  Replace its contents with:

``` java
package com.example.maven_github_demo;

import static org.junit.jupiter.api.Assertions.*;

import org.junit.jupiter.api.Test;

class GradeCalculatorTest {

    @Test
    void testTotal() {
        assertEquals(225,
                GradeCalculator.calculateTotal(75, 68, 82));
    }

    @Test
    void testAverage() {
        assertEquals(75.0,
                GradeCalculator.calculateAverage(75, 68, 82));
    }

    @Test
    void testPass() {
        assertTrue(GradeCalculator.isPass(75.0));
    }

    @Test
    void testFail() {
        assertFalse(GradeCalculator.isPass(35.0));
    }
}
```

5.  Save the file.
6.  Right-click `GradeCalculatorTest.java` and select **Run As → JUnit
    Test**.
7.  Verify that all four tests pass.

Expected result:

``` text
Tests run: 4
Failures: 0
Errors: 0
```

## 6. Update the Maven project

After editing `pom.xml`:

1.  Right-click the project.
2.  Select **Maven → Update Project**.
3.  Select the project.
4.  Check **Force Update of Snapshots/Releases** if required.
5.  Click **OK** and wait for Maven dependencies to download.

If the JUnit imports are unresolved, check that the JUnit 5 dependency
is present in `pom.xml` and update the Maven project.

## 7. Execute Maven build goals

For each goal:

1.  Right-click the project.
2.  Select **Run As → Maven build...**.
3.  Enter the goal in the **Goals** field.
4.  Click **Run** and inspect the Console.

Run these goals:

  -----------------------------------------------------------------------
  Goal                                Purpose
  ----------------------------------- -----------------------------------
  `clean`                             Removes files from the previous
                                      Maven build, including the `target`
                                      directory.

  `test`                              Compiles the project and runs the
                                      JUnit tests.

  `clean package`                     Cleans, compiles, tests, and
                                      packages the application into a
                                      JAR.
  -----------------------------------------------------------------------

The final command to generate the JAR is:

``` bash
mvn clean package
```

After a successful package build, refresh the project in Eclipse
(right-click the project → **Refresh**, or press **F5**) and expand
`target`.

Expected generated file:

``` text
target/maven-github-demo-1.0-SNAPSHOT.jar
```

The JAR is created by the `package` phase, not by `clean` alone.

## 8. Configure Git

Open a terminal in the project root directory (the folder containing
`pom.xml`).

Configure your Git identity. Replace the example values with the name
and email associated with your Git commits:

``` bash
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
```

Initialize Git and make the first commit:

``` bash
git init
git add .
git commit -m "Initial commit"
```

## 9. Create a GitHub repository and push the project

1.  Sign in to GitHub.
2.  Create a new repository named `maven-github-demo`.
3.  Copy the repository's HTTPS URL.
4.  In the project terminal, connect the local repository to GitHub.
    Replace the URL below with your repository URL:

``` bash
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/maven-github-demo.git
git push -u origin main
```

If the `origin` remote already exists, update it instead of adding it
again:

``` bash
git remote set-url origin https://github.com/YOUR-USERNAME/maven-github-demo.git
```

## 10. Add the GitHub Actions workflow

In the project root, create the following folders and file:

``` text
maven-github-demo/
└── .github/
    └── workflows/
        └── maven.yml
```

Add this workflow to `maven.yml`:

``` yaml
name: Maven Build

on:
  push:
    branches: ["main"]
  pull_request:
    branches: ["main"]

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
      - name: Checkout source code
        uses: actions/checkout@v4

      - name: Set up JDK
        uses: actions/setup-java@v4
        with:
          java-version: '17'
          distribution: 'temurin'
          cache: maven

      - name: Build with Maven
        run: mvn clean package
```

Save the workflow file, then commit and push it:

``` bash
git add .
git commit -m "Add Maven GitHub Actions workflow"
git push origin main
```

## 11. Verify the GitHub Actions build

1.  Open the GitHub repository.
2.  Select the **Actions** tab.
3.  Open the workflow named **Maven Build**.
4.  Select the latest run.
5.  Open the **Build with Maven** step.
6.  Verify that the build completes successfully.

The workflow runs when code is pushed to `main` or when a pull request
targeting `main` is opened or updated.

## 12. Demonstrate a failed GitHub Actions build

To demonstrate a build failure (not merely a failed JUnit assertion),
temporarily introduce a Java compilation error.

In `GradeCalculator.java`, change:

``` java
return m1 + m2 + m3;
```

temporarily to:

``` java
return m1 + m2 + unknownVariable;
```

The variable `unknownVariable` is not declared, so Java compilation
should fail.

Commit and push this intentional error:

``` bash
git add .
git commit -m "Demonstrate failed Maven build"
git push origin main
```

Then:

1.  Open GitHub → **Actions**.
2.  Open the latest **Maven Build** run.
3.  Inspect the failed **Build with Maven** step.
4.  Confirm that the build failed because of a compilation error.

Do not leave the intentional error in the final project.

## 13. Restore the code and verify a successful build

Restore the original method:

``` java
public static int calculateTotal(int m1, int m2, int m3) {
    return m1 + m2 + m3;
}
```

Then commit and push the correction:

``` bash
git add .
git commit -m "Fix compilation error and restore successful build"
git push origin main
```

Open GitHub → **Actions** and verify that the latest Maven Build run
succeeds.

## Result

A Maven-based Java Grade Calculator project was created in Eclipse.
JUnit 5 tests were executed, Maven build goals were verified, a JAR file
was generated, and the project was pushed to GitHub. GitHub Actions was
configured to build the project automatically. A failed build was
demonstrated using a temporary compilation error, after which the code
was restored and a successful build was verified.
